# Workspace Operating Instructions

These instructions apply to every agent and every task in this workspace.

## Mandatory memory preflight

Before planning, drafting, editing, reviewing, or implementing any task, read
[`BRAND_MEMORY.md`](./BRAND_MEMORY.md) in full. This is a required preflight, not
an optional reference.

For brand, marketing, sales, advertising, campaign, social, email, website,
SEO, creative, audience, offer, or customer-facing work, an agent MUST NOT begin
the deliverable until it has:

1. Read the memory file.
2. Identified the relevant audience, offer, message, proof, funnel stage,
   channel, and voice rules.
3. Checked the request against the Brand Alignment Gate in the memory file.
4. Marked unknown information as unknown instead of inventing it.

If the memory and the user's latest explicit instruction conflict, follow the
user and record the new decision in the memory. If two stored facts conflict,
follow the source-priority rules in the memory and preserve the conflict in the
Open Questions section until it is resolved.

## Mandatory memory write-back

At the end of a task, update `BRAND_MEMORY.md` when the work reveals or creates
durable information, including:

- a confirmed brand, audience, offer, voice, or channel decision;
- an approved or rejected phrase, message, claim, or creative direction;
- new proof, customer language, research, or campaign performance;
- a contradiction, constraint, compliance rule, or unresolved question;
- a reusable lesson likely to improve future work.

Do not write back brainstorms, disposable drafts, generic advice, or unsupported
assumptions. Label new entries using the evidence states defined in the memory.
Update the `Last updated` line and append a short entry to the Change Log.

Never silently overwrite an established decision. Mark it superseded, explain
why, and link the replacement decision.

## Delivery requirements

Every customer-facing deliverable must be traceable to the memory's audience,
message, proof, offer, and voice guidance. Before delivery, run the Brand
Alignment Gate. In the final response, briefly state whether the memory was
consulted and whether durable knowledge was added.

When the memory lacks essential context, make the smallest safe assumption,
label it `[INFERRED]`, and keep claims conservative. Ask the user only when the
missing information would materially change the result or create brand, legal,
financial, or reputational risk.
