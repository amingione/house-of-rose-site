# Brand Governance Framework — House of Rose Aesthetics
*Generated via 11/01 · 2026-06-21 · lightweight, for a small team.*

## Decision ownership
- **Brand owner (Amber):** final approver of positioning, visual identity, naming, and any change to
  the locked foundation (Phases 01–03).
- **Marketing/lead:** day-to-day content within the guidelines (social, blog, email, ads).
- **Providers/front desk:** client-facing language per Voice + compliance; escalate edge cases.

## Approval workflow (tiers)
- **Tier A — no review needed:** on-template content that follows the Quick Reference (social posts,
  routine emails, blog using approved templates).
- **Tier B — marketing review:** new campaigns, landing pages, ads, partnerships.
- **Tier C — owner approval:** anything touching positioning, category language, logo, pricing
  framing, new lanes, or the foundation docs.

## Escalation (off-brand / compliance)
Anyone who spots a violation (self-labeled "luxury/medical," single-treatment tunnel, guarantee
language, off-palette logo, flat pricing) flags it → fix or escalate to owner → log in the change log.
Run the **Systems Auditor** (`SYSTEMS-AUDITOR.md`) on new major docs before publishing.

## Cadence
Quarterly brand review (10-02); change log kept continuously; foundation revisited only deliberately
(11-03).
