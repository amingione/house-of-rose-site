# Brand Refresh / Evolution Plan — House of Rose Aesthetics
*Generated via 11/03 · 2026-06-21.*

## Refresh triggers
Real signals only: meaningful change in services/lanes, a location move, sustained perception/audit
findings, competitive shifts, or 2–3 years elapsed. Not trends or boredom.

## Scope: evolve vs core
- **Core (don't reopen lightly):** category ("Advanced Aesthetics"), tagline ("Where beauty blooms
  within"), the HR monogram, positioning keystone, honesty + full-house principles.
- **Can evolve:** photography library, campaign themes, secondary palette extensions, web layout,
  service mix, supporting copy.

## Rollout & communication
Stage changes (internal first → digital → print/packaging as stock cycles); update the Brand Book
version; brief the team (Phase 09); communicate externally only when client-visible and worth a story.

## Safeguards
Any core change requires owner approval (11-01) + a Systems Auditor pass + a change-log entry.
Preserve consistency: never half-migrate (avoid the "two logos in the wild" problem).
