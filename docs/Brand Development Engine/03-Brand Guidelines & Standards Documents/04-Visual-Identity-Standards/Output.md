# Visual Identity Standards — House of Rose Aesthetics
*Generated via 03/04 · 2026-06-21 · how the elements combine. Compiles Phase 02.*

## Layout grid, margins & spacing
- **Grid:** 12-col, 80px max gutters; generous outer margins (≥8% viewport / ≥0.5in print).
- **Spacing rhythm:** 8px base scale; **large section padding** (96px+ desktop) — whitespace is the
  luxury cue.
- **Measure:** body 60–75 characters; never edge-to-edge text.

## Element combination rules
- **Every section opens** with a Montserrat tracked **eyebrow** over a Cormorant **heading**.
- **Logo placement:** wordmark top-left in headers; monogram for tight/footer/seal moments.
- **Image + text:** text on calm areas; maintain clear space around the mark; one focal image per block.
- **Color proportion:** 60 ivory/greige · 30 ink/burgundy · 10 gold + botanical. Gold only as accent.
- **Pattern/accent restraint:** one quiet pattern per surface, low opacity, lots of space.

## Alignment & hierarchy
- Left-aligned by default; centered only for hero/tagline moments.
- One clear focal point per view; size + space create hierarchy, not heavy weights or boxes.
- Editorial asymmetry welcome; avoid clutter and competing accents.

## Annotated example layouts
1. **Web hero:** ivory ground · eyebrow + large Cormorant headline left · warm editorial image right ·
   burgundy "Book Now" CTA · gold hairline divider below.
2. **Service card:** image top · eyebrow (lane) · title · 1-line outcome · "From $X" · ghost CTA ·
   hairline border → gold on hover.
3. **Print one-sheet:** greige paper texture · monogram top-center · gold rule + rose tick dividers ·
   two-column Cormorant/EB Garamond · footer NAP + tagline.

## New-asset cohesion checklist
- [ ] Eyebrow+heading present? · [ ] 60/30/10 color? · [ ] Gold only as accent? · [ ] Whitespace
  generous? · [ ] Warm/editorial, not clinical? · [ ] "From $X" if pricing? · [ ] Mark clear space
  respected? · [ ] Reads unmistakably House of Rose?
