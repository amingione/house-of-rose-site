# Prompt Template — Icon Set
*House of Rose Aesthetics · 02 Visual Identity · run with an AI execution agent (and a designer).*

## ROLE
You are an iconographer and systems designer. You define an icon language that's consistent,
scalable, and unmistakably on-brand.

## GOAL
Produce an **Icon Set** spec for House of Rose Aesthetics: style, grid, weight, and the core icon
list spanning the full destination — derived from the brand's elegant, fashion-house feel.

## BRAND CONTEXT (inherit — do not contradict)
- House of Rose Aesthetics · Punta Gorda, FL · by appointment. Tagline: **"Where beauty blooms within."**
- Category: **Advanced Aesthetics** — never medical / med spa / boutique / luxury self-label.
- A **full destination** — icons should cover all lanes (skin, injectables, wellness, beauty,
  membership), not just one treatment.
- **Energy → visual:** fresh, modern, radiant + bold, iconic; **fashion-house elegance** with
  subtle rose/bloom and gold cues. Refined line work — not clip-art, not clinical symbols.
- (Full brief: `../01-Strategy & Foundation Documents/00-HoR-Brand-Context.md`.)

## INSTRUCTIONS (think step by step)
1. Define the icon **style** (line vs solid, corner radius, stroke weight, level of detail) so it
   harmonizes with the logo lettering.
2. Specify the **grid & sizing** system (e.g., 24px base, keylines, padding) for pixel consistency.
3. List the **core icon set** mapped to the full destination (service categories, booking, gift,
   membership, location, contact, social).
4. Define color usage (mono, gold accent) and export formats (SVG primary, sizes).
5. Give do/don't rules for consistency.

## OUTPUT FORMAT
### Icon style & weight
### Grid & sizing system
### Core icon list (by category)
### Color & export formats
### Do / Don't

## QUALITY CONTROL (self-check before finishing)
- [ ] Style harmonizes with the logo + fashion-house elegance (not clip-art, not clinical).
- [ ] Covers the full destination's categories.
- [ ] Grid/weight/format specs make it production-consistent.
- [ ] ANTI-GENERIC: if the set could be any spa's, refine until unmistakably House of Rose.
