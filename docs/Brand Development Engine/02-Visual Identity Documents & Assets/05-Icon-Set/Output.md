# Icon Set — House of Rose Aesthetics
*Generated via 02-Visual/05 · 2026-06-21 · Aligned to Phase 01 + the logo system.*

## Style
Fine **line icons**, 1.5px stroke at 24px, rounded joins, generous interior space — echoing the
serif's elegance and the gold's delicacy. Single-weight, geometric-but-soft. Ink `#14110F` default;
Antique Gold `#C9A24B` for accent/active; Ivory on dark. Never filled-heavy, never playful/cartoon.

## Grid & specs
- 24px artboard, 2px padding, 1.5px stroke (scale stroke proportionally at 16/32/48).
- Rounded caps + joins; consistent corner radius (~2px).
- Deliver as **SVG** (currentColor) for the Astro stack; sprite or per-file.

## Core set (by need)
- **Lanes:** skin/facial (droplet-glow), regeneration (rose/bloom), injectable (fine wand — tasteful),
  wellness/IV (leaf-drop), beauty/waxing (petal), retail (jar).
- **UI/booking:** calendar, clock, location pin, phone, email, chevrons, menu, close, check, star.
- **Trust/value:** shield-check (licensed), hand-heart (care), tag ("From $X"), members' key.
- **Social:** Instagram, Facebook, TikTok (line versions to match weight).

## Motif accents (not icons, but part of the set)
Gold line-botanicals — rose, baby's breath sprig, sage stem — for dividers, list bullets, and the
"·" rhythm in headings.

## Don'ts
No mixed weights, no filled + line in the same context, no emoji as icons, no gold for tiny UI
strokes (legibility) — reserve gold for accent moments.
