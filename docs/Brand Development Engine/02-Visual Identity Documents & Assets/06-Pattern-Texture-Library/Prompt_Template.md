# Prompt Template — Pattern & Texture Library
*House of Rose Aesthetics · 02 Visual Identity · run with an AI execution agent (and a designer).*

## ROLE
You are a surface/pattern designer. You create signature graphic elements that make a brand instantly
recognizable across collateral.

## GOAL
Produce a **Pattern & Texture Library** spec for House of Rose Aesthetics: the repeating motifs,
textures, and graphic devices (rooted in the rose/bloom and the monogram) plus usage rules.

## BRAND CONTEXT (inherit — do not contradict)
- House of Rose Aesthetics · Punta Gorda, FL · by appointment. Tagline: **"Where beauty blooms within."**
- Category: **Advanced Aesthetics** — never medical / med spa / boutique / luxury self-label.
- A **full destination** — patterns are brand-wide, used across all lanes' collateral.
- **Energy → visual:** fresh, modern, radiant + bold, iconic; **fashion-house** signature motifs
  (think a recognizable monogram/petal pattern, foil/gold accents, fine line frames) with rose/bloom
  romance. Refined and editorial — never busy, never clinical.
- (Full brief: `../01-Strategy & Foundation Documents/00-HoR-Brand-Context.md`.)

## INPUT (fill before running)
- Motifs to build from (rose, petal, HR monogram, the "bloom" idea):
- Where patterns appear (packaging, cards, gift cards, social frames, signage, web backgrounds):
- Print finishes available (foil, emboss, matte):

## INSTRUCTIONS (think step by step)
1. Define 2–4 signature elements (e.g., a monogram repeat, a petal/bloom motif, a fine gold frame,
   a subtle texture) — each with a clear concept.
2. Specify scale, spacing, color treatment, and where each is used vs not used.
3. Define a restraint rule (patterns support, never overwhelm — fashion-house, not floral overload).
4. Note formats and print finish pairings (foil/gold, emboss).

## OUTPUT FORMAT
### Signature elements (each with concept + usage)
### Scale, spacing & color treatment
### Restraint rules (do / don't)
### Formats & print finishes

## QUALITY CONTROL (self-check before finishing)
- [ ] Motifs root in the rose/bloom + monogram — unmistakably House of Rose.
- [ ] Fashion-house refinement; supportive, never busy or clinical.
- [ ] Usage + restraint rules clear; production formats noted.
- [ ] ANTI-GENERIC: if the patterns could be any spa's, refine until unmistakably House of Rose.
