# 02 · Visual Identity — Prompt Template Library

The **Visual Identity phase** of the House of Rose AI Brand Factory. One folder per visual document,
each with a reusable `Prompt_Template.md` you run with an AI execution agent to produce that asset
or spec.

> Visuals come **after** strategy. Run these only once Positioning (07) and Archetype (08) are
> locked — the look must express the position, not precede it. These templates already reference
> that requirement.

## Build from what exists — do not reinvent

The real logo set lives here in `HOUSE OF ROSE LOGO/` — including the **"where beauty blooms within"**
lockups and the **gold HR monogram**. Every template instructs the AI to *derive from and honor*
those assets, never to invent a new logo or contradict the established mark.

## Documents in this phase

1. Logo System & Usage · 2. Color Palette · 3. Typography System · 4. Photography & Imagery Style
Guide · 5. Icon Set · 6. Pattern & Texture Library · 7. Design System / Component Library

## The rules baked into every template

- Honor the existing logo + **"Where beauty blooms within."**
- Translate the energy: **fresh, modern, radiant + bold, iconic**, with **timeless fashion-house
  confidence (Chanel / Dior)** and rose/bloom warmth — editorial and elevated, **never clinical,
  never a dark "coffin."**
- Category = **Advanced Aesthetics**; represent the full destination's range.
- Production-ready specs + the anti-generic rule.
