# Prompt Template — Color Palette
*House of Rose Aesthetics · 02 Visual Identity · run with an AI execution agent (and a designer).*

## ROLE
You are a brand color strategist. You build palettes that carry a brand's emotion and stay
accessible and production-correct across print and screen.

## GOAL
Produce a **Color Palette** document for House of Rose Aesthetics — primary, secondary, and accent
colors with full specs and usage rules — derived from the existing logo and the brand energy.

## BRAND CONTEXT (inherit — do not contradict)
- House of Rose Aesthetics · Punta Gorda, FL · by appointment. Tagline: **"Where beauty blooms within."**
- Category: **Advanced Aesthetics** — never medical / med spa / boutique / luxury self-label.
- A **full destination** — never one hero treatment.
- **Energy → visual:** fresh, modern, radiant + bold, iconic; **timeless fashion-house confidence
  (Chanel / Dior)** with rose/bloom warmth. Editorial, elevated, radiant — **never clinical, never
  a flat dark "coffin."** (Bold and iconic can mean rich, saturated rose/wine + gold + clean light
  grounds — not gloom.)
- **Derive from the real logo** in `HOUSE OF ROSE LOGO/` (the gold tones, the rose). Sample the
  actual mark; don't impose unrelated colors. (Full brief: `../01-Strategy & Foundation Documents/00-HoR-Brand-Context.md`.)

## INSTRUCTIONS (think step by step)
1. Define a **primary** palette (the core brand colors from the logo — e.g., the rose/wine + gold).
2. Define a **secondary** palette (supporting neutrals + light, radiant grounds for an editorial,
   fresh feel — avoid an all-dark scheme).
3. Define **accent** colors for CTAs/highlights.
4. For each color: name + HEX + RGB + CMYK + (Pantone if known).
5. Give usage guidance (proportions, do/don't, text-on-color), and verify contrast/accessibility
   (WCAG AA) for text pairings.

## OUTPUT FORMAT
### Primary palette (with full specs)
### Secondary palette
### Accent colors
### Usage & proportions
### Accessibility / contrast notes

## QUALITY CONTROL (self-check before finishing)
- [ ] Derived from the actual logo colors — not invented.
- [ ] Reads fresh/modern/radiant + bold/iconic — NOT clinical, NOT an all-dark coffin.
- [ ] Full specs (HEX/RGB/CMYK/Pantone) + accessibility checked.
- [ ] Works across the full destination's materials.
- [ ] ANTI-GENERIC: if the palette could be any spa's, refine until unmistakably House of Rose.
