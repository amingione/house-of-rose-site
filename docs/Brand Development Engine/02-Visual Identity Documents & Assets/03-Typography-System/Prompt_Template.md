# Prompt Template — Typography System
*House of Rose Aesthetics · 02 Visual Identity · run with an AI execution agent (and a designer).*

## ROLE
You are a brand typographer. You define a type system that feels editorial and elevated and works
flawlessly across print and screen.

## GOAL
Produce a **Typography System** for House of Rose Aesthetics — font families, hierarchy, sizing,
and usage — expressing fashion-house confidence and pairing with the existing logo.

## BRAND CONTEXT (inherit — do not contradict)
- House of Rose Aesthetics · Punta Gorda, FL · by appointment. Tagline: **"Where beauty blooms within."**
- Category: **Advanced Aesthetics** — never medical / med spa / boutique / luxury self-label.
- A **full destination** — never one hero treatment.
- **Energy → visual:** fresh, modern, radiant + bold, iconic; **timeless fashion-house confidence
  (Chanel / Dior)** — think refined display serif or elegant high-contrast type for headlines,
  paired with a clean, modern sans for body. Editorial and elevated, not clinical.
- **Pair with the logo's lettering** in `HOUSE OF ROSE LOGO/` — typography should feel of-a-piece
  with the mark and tagline. (Full brief: `../01-Strategy & Foundation Documents/00-HoR-Brand-Context.md`.)

## INPUT (fill before running)
- Fonts used in the existing logo / any fonts already chosen:
- Licensing constraints (web fonts available, budget):
- Channels (print collateral, signage, website, social, email):

## INSTRUCTIONS (think step by step)
1. Recommend a **primary (display/heading)** typeface and a **secondary (body)** typeface — name
   specific, licensable fonts (with web-safe / Google Fonts fallbacks).
2. Define the heading hierarchy (H1–H6) with sizes, weights, and line-heights.
3. Define body text sizing, line-height, and measure.
4. Specify pairings, casing (sentence case — no ALL CAPS for emphasis), tracking for the
   fashion-house feel, and accent uses (e.g., italics for the tagline).
5. Note font licensing details and fallbacks.

## OUTPUT FORMAT
### Primary (display) + Secondary (body) typefaces
### Heading hierarchy (H1–H6 specs)
### Body text specs
### Pairing, casing & tracking rules
### Licensing & fallbacks

## QUALITY CONTROL (self-check before finishing)
- [ ] Feels editorial / fashion-house, pairs with the logo lettering.
- [ ] Specific, licensable fonts named (with fallbacks) — not vague "a serif."
- [ ] Full hierarchy + body specs; sentence case enforced.
- [ ] Not clinical; works across the full destination's materials.
- [ ] ANTI-GENERIC: if the system could be any spa's, refine until unmistakably House of Rose.
