# 01 · Strategy & Foundation — Prompt Template Library

This folder is the **Strategy phase** of the House of Rose AI Brand Factory. It holds one folder
per foundational brand document, and inside each is a **reusable prompt template** you run with an
AI execution agent to generate that document.

> Strategy comes first. Everything downstream (visual identity, messaging, web, campaigns) must
> ladder back to what's defined here.

## How to use a template

1. Open the document's folder → `Prompt_Template.md`.
2. Fill the **INPUT** section (the few brand specifics that template needs).
3. Run it with an AI agent (Claude, etc.). The embedded **Brand Context** keeps the output
   on-brand; the **Quality Control** block forces specificity.
4. Save the generated document next to the template (or in `0-Positioning House of Rose/`).

## The pipeline behind each template (your AI Brand Factory)

`Research Analyst → Brand Architect → Prompt Engineer → Systems Auditor`. These templates are the
**Prompt Engineer** output — ready to execute. When you're ready for the research-backed version,

## Build order (dependencies)

1. Mission · 2. Vision · 3. Values · 4. Personas · 5. Competitive Analysis · 6. UVP ·
7. Positioning · 8. Archetype · 9. Voice & Tone · 10. Promise · 11. Brand Story

Positioning (07) is the keystone — Personas (04) and Competitive Analysis (05) feed it; everything
after reinforces it.

## The rules baked into every template

- Category = **Advanced Aesthetics** (never medical / boutique / luxury self-label).
- **Full destination**, never one hero treatment (don't tunnel on PRF/microchanneling).
- Energy = fresh, modern, radiant + bold, iconic; timeless fashion-house confidence.
- Tagline = **"Where beauty blooms within."**
- Compliance guardrails + the anti-generic rule.

See `00-HoR-Brand-Context.md` for the full inherited brief.
