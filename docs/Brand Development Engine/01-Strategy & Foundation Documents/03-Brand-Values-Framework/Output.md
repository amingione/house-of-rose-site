# Brand Values Framework — House of Rose Aesthetics
*Generated via 01-Strategy/03 template · 2026-06-21 · aligned to Positioning keystone (01-07).*

Five values. Each has a meaning, a behavior (how it shows up), and a guardrail (what it forbids).
Values without behaviors are decoration — these are operational.

## 1. Results, Built Right
**Meaning:** Real, lasting change beats a temporary fix. We work with the body, in sequence, over time.
**Behavior:** We design treatment in phases (the Rose Method™), recommend series and maintenance
honestly, and use regenerative methods (PRF, collagen induction) where they serve the result.
**Guardrail:** Never promise a result we can't responsibly support; never push the "more is better"
over-treated look.

## 2. Expertise, Worn Lightly
**Meaning:** Deep clinical knowledge delivered with warmth — credible, never cold or intimidating.
**Behavior:** Providers explain the *why* in plain language; education comes before treatment. We're
CARE-certified in PRF and proud of the rigor behind every protocol across every lane.
**Guardrail:** No jargon-as-status, no condescension, no pressure dressed up as advice.

## 3. Honesty as the Standard
**Meaning:** Transparency *is* the premium. Honest pricing, honest candidacy, honest expectations.
**Behavior:** We tell clients when something isn't right, when to wait, and what it truly costs.
We'd rather decline than oversell. Pricing reads "From $X."
**Guardrail:** No hidden fees, no fear-selling, no units a client doesn't need.

## 4. Quiet Refinement
**Meaning:** True refinement is understated. Restraint signals confidence; loudness signals insecurity.
**Behavior:** Calm spaces, considered language, results that whisper. Reads like a destination, never
a deal — fashion-house confidence, never clinical, never a coffin.
**Guardrail:** No hype, no urgency gimmicks, no coupon energy, no clutter.

## 5. The Client, Cared For
**Meaning:** Every person is met as an individual on a personal journey — discretion and hospitality
are non-negotiable.
**Behavior:** By-appointment intimacy, personalized plans, follow-through between visits, a
relationship that outlasts any single treatment.
**Guardrail:** Never treat a client as a transaction or a number on the calendar.

### Using this framework
Run any decision — a new service, a price, an ad, a word on the website — against the five. If it
violates a guardrail, stop. If it can't be tied to a value, reconsider.
