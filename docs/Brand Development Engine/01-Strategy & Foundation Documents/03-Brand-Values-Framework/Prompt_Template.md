# Prompt Template — Brand Values Framework
*House of Rose Aesthetics · 01 Strategy & Foundation · run with an AI execution agent.*

## ROLE
You are a brand strategist who turns values into operational behavior — not wall art. Each value
must have a meaning, a behavior, and a guardrail.

## GOAL
Produce a **Brand Values Framework** for House of Rose Aesthetics: 5 core values that drive real
decisions across the whole destination.

## BRAND CONTEXT (inherit — do not contradict)
- House of Rose Aesthetics · Punta Gorda, FL · by appointment. Tagline: **"Where beauty blooms within."**
- Category: **Advanced Aesthetics** — never medical / med spa / boutique / luxury self-label; the
  elevated feeling is experienced, never self-proclaimed.
- A **full destination** (skin, regeneration, injectables, wellness, beauty, memberships, the
  experience) — never one hero treatment; don't over-index on PRF/microchanneling.
- Energy: fresh, modern, radiant + bold, iconic; timeless fashion-house confidence (Chanel / Dior)
  with rose/bloom warmth.
- Voice: confident not loud; specific over superlative; warm + expert.
- Compliance: no guarantees; defer to licensed providers; individual results. (Full brief: `00-HoR-Brand-Context.md`)

- 3–8 candidate values or beliefs Amber holds about the business:
- A story/moment that shows the brand at its best:
- Any behavior you never want to see in the studio:

## INSTRUCTIONS (think step by step)
1. Cluster the inputs into exactly **5 distinct values** (avoid overlap).
2. For each value, write: **Meaning** (1 line) · **Behavior** (how it shows up in practice across
   the whole destination) · **Guardrail** (what it forbids).
3. Make values ownable — a generic "excellence/integrity" set is a failure.
4. Add a one-paragraph note on how to use the framework to vet decisions.

## OUTPUT FORMAT
### Value 1–5 (each with Meaning · Behavior · Guardrail)
### Using this framework

- [ ] Exactly 5, distinct, ownable values — not generic virtues.
- [ ] Each has a concrete behavior + a guardrail.
- [ ] Reflects the full destination + the experience; no treatment tunnel.
- [ ] Category = Advanced Aesthetics; no medical/boutique/luxury self-labeling.
- [ ] ANTI-GENERIC: if a value could belong to any spa, rewrite until unmistakably House of Rose.
