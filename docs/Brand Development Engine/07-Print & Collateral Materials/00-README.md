# 07 · Print & Collateral — Prompt Template Library

The **physical touchpoint layer**. Templates for printed pieces a client sees and holds — each built from the logo, color, and type system so the felt experience carries off-screen.

> Run after phases 02–03. Build from the real logo + visual standards; never clinical, never a coffin.

## Documents in this phase

1. Business Card · 2. Letterhead · 3. Envelope · 4. Email Signature · 5. Brochure / One-Sheet · 6. Flyer / Poster · 7. Thank You Card · 8. Invoice / Receipt Template · 9. Proposal / Quote Template

## The rules baked into every template

- Category = **Advanced Aesthetics**; **full destination**; tagline **"Where beauty blooms within."**
- Energy = fresh, modern, radiant + bold, iconic; fashion-house confidence — **never clinical, never a coffin.**
- Felt-luxury (never self-claimed) · on-voice · compliant · "From $X"/range pricing · the anti-generic rule.
