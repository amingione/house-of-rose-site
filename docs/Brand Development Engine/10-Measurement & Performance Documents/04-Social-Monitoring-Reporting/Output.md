# Social Monitoring & Reporting — House of Rose Aesthetics
*Generated via 10/04 · 2026-06-21 · sentiment, mentions, engagement.*

## Monitoring scope & tools
Track: @mentions, tags, brand + local hashtags, Google/Facebook reviews, DMs. Tools: native
insights + Google Business Profile + a listening tool (or manual weekly sweep).

## Metrics & cadence
Reach, engagement rate, saves/shares, follower quality (local %), DM→consult, review rating/volume,
sentiment (pos/neutral/neg). Weekly pulse + monthly report.

## Report layout (insights → actions)
Snapshot KPIs → top posts (and why) → sentiment summary → notable mentions/reviews → 3 actions for
next month. Tie back to the content calendar (06-01) + pillars.

## Escalation
Negative reviews/comments or compliance-risk posts → notify owner same day; respond on-voice (warm,
no medical advice, take detailed issues offline). Never argue publicly.
